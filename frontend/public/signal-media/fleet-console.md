# Captures de la console xSOM Fleet (page fleet.xsom.fr, chapitre FinOps)

- Source : console xSOM Fleet (`plateforme.xsom.fr`), Groupe de démonstration créé par
  `fleet-ops demo-data generate` sur une base jetable ; septembre 2026. Données
  illustratives : aucun client, adresses sous `demo.invalid`.
- `fleet-console-costs.webp` : page « Coûts », vue Groupe (3200 × 1700, haut de page).
- `fleet-console-seats.webp` : page « Organisations fournisseur » (3200 × 1220, haut de page).
- Fidélité : captures Chromium à l’échelle 2, recadrées en hauteur seulement, puis
  `cwebp -q 84`. Aucun chiffre retouché ; le bandeau « Démonstration · données
  illustratives » de la console est conservé, et la page en ajoute un dans le cadre.
- Images Open Graph `xsom-fleet-og-{fr,en}.jpg` et `xsom-ia-og-{fr,en}.jpg` : couverture
  de chaque page capturée à 1920 × 1008 puis réduite à 1200 × 630.
